## 通用验收项

每个平台都必须完成以下项目，记录设备、时间、结果和证据：

- [ ] 导入匹配通道的 GeoData（domain + ip）后安装匹配的 Profile。
- [ ] 连接成功，状态页显示已连接。
- [ ] 主节点切换：切换主节点后，FOLLOW 业务和最终兜底跟随变化。
- [ ] 固定业务隔离：固定节点业务始终走固定节点，主节点切换不影响它。
- [ ] DNS 分流：国内域名走国内 DNS/直连，境外域名走境外 DNS/代理。
- [ ] 本地直连：localhost、.lan、.local 与私有 IP 直连。
- [ ] 海外 FOLLOW：GitHub、YouTube、OpenAI、海外流媒体/社交跟随主节点。
- [ ] ChinaIP 晚直连：未知域名解析为国内 IP 后按规则直连。
- [ ] QUIC/Block/IPv6：按 `quicMode` 和 `ipv6Mode` 重跑对应用例。
- [ ] 节点刷新/重启：刷新节点订阅并重启 VPN 后，主节点候选更新且固定快照不变。
- [ ] 固定失败：固定节点故障时只有该业务失败，且不会自动回退或通知。
- [ ] 链关闭/开启：`clientChain=off` 与 `clientChain=on` 都验证 FOLLOW 链路，固定/直连/拦截路径不受链影响。
- [ ] Profile 回滚：previous Profile 与 previous GeoData 配对后能恢复连接。
- [ ] GeoData 回滚：previous GeoData 安装后，规则命中与 Profile 通道一致。
